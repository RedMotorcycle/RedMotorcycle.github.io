Valor Board 개인정보 처리방침

최종 수정일: 2026년 4월 13일

본 애플리케이션을 사용함으로써 본 개인정보 처리방침에 동의하게 됩니다.

사용자는 앱의 첫 사용 시 또는 방침이 개정되었을 때 동의 화면에서 최신 방침을 확인해야 합니다.

연령 제한

본 애플리케이션은 16세 이상의 사용자를 대상으로 합니다. 이는 Riot Games의 계정 생성 요구 사항을 준수합니다. 16세 미만의 사용자는 사용 전 보호자의 동의를 얻어야 합니다.

수집 및 이용하는 데이터

Riot Games API를 통해 수집하는 데이터

  • Riot ID (게임 이름 #태그라인)
  • 계정 정보 (PUUID와 같은 식별자)
  • 매치 기록 및 전적 데이터
  • 랭크 정보

본 애플리케이션은 Riot Games API를 통해 플레이어의 매치 기록 및 랭크 정보를 조회하고 표시합니다.

개인 매치 데이터(매치 기록, 상세 통계, 대시보드 기능 등)를 확인하려면, 데이터 소유권을 확인하고 개인정보를 보호하기 위해 Riot Sign On (RSO)을 통한 사용자 인증(옵트인)이 필요합니다.

RSO를 통해 인증함으로써, 귀하는 플레이어 데이터가 본 애플리케이션에 의해 수집, 분석 및 표시되는 것에 동의(옵트인)하게 됩니다.

기기에 저장되는 데이터

  • 인증 토큰 (안전한 암호화 저장소에 저장됨)
  • 사용자 설정 및 애플리케이션 구성
  • 캐시 데이터 (게임 콘텐츠 정보 등)
  • Lineup 기능에 사용되는 이미지 및 동영상 (기기에만 저장되며 외부 서버로 전송되지 않음)

서버로 전송되는 데이터

  • Firebase Analytics: 앱 사용 데이터 (개인 식별 정보 포함되지 않음)
  • Firebase Performance Monitoring: 앱 성능 데이터 (예: 통신 속도, 화면 렌더링 속도)
  • Firebase Crashlytics: 크래시 리포트 (기기 정보 포함)
  • Cloud Firestore: 사용자 PUUID, Riot ID(게임 이름#태그라인), 동의 정보, 및 가입 날짜 (앱 사용자 간의 데이터 검증용)
  • Firebase App Check: 앱 및 기기 정품 인증을 위한 토큰 (Google Play Integrity API / Apple DeviceCheck / App Attest)
  • Firebase Authentication: 로그인 인증, PUUID 관리 (사용자 식별)
  • Google AdMob: 광고 식별자 (IDFA/AAID), 기기 정보 및 상호작용 데이터 (광고 제공 및 분석용)

데이터 보유 및 삭제

데이터 저장 위치

  • 기기 저장소: 인증 정보, 설정, 캐시
  • Firebase 서버 (Google Cloud): 분석 데이터, 성능 데이터, 크래시 리포트
  • Cloud Firestore (Google Cloud / 도쿄 리전): 옵트인 사용자 식별자 (PUUID)
  • Firebase Authentication (Google Cloud / 도쿄 리전): 인증 토큰, PUUID
  • Google AdMob 서버: 광고 관련 데이터

본 애플리케이션은 자체 서버에서 데이터를 수집하지 않으며, 기능을 제공하기 위해 앞서 언급한 Firebase 서비스와 Google AdMob을 사용합니다.

데이터 보유 기간

  • 기기 데이터: 앱이 삭제될 때까지
  • Firebase Analytics: Google의 데이터 보유 정책을 따름
  • Firebase Performance Monitoring: 90일
  • Firebase Crashlytics: 90일
  • Google AdMob: Google의 데이터 보유 정책을 따름

데이터 삭제 방법

기기의 데이터는 앱을 삭제하면 제거됩니다. Firebase 및 AdMob으로 전송된 데이터는 Google의 정책에 따라 처리됩니다.

사용자의 권리 및 옵트아웃

사용자는 자신의 데이터와 관련하여 다음과 같은 권리를 가집니다:

  • 데이터 수집에 대한 동의 철회 (옵트아웃)
  • 기기 데이터의 완전한 삭제
  • 개인 맞춤형 광고 수신 거부 (기기 설정을 통해)

권리 행사 및 데이터 삭제

다음 작업을 수행하여 데이터 사용을 중단하고 데이터를 삭제할 수 있습니다:

  • 앱에서 로그아웃 (RSO 연동 해제):
    앱 내의 설정 화면에서 로그아웃해 주십시오. 로그아웃 시 '전적 숨기기' 옵션을 선택하면 서버에 등록된 옵트인 정보를 삭제할 수 있습니다. 이 옵션을 선택하지 않으면 다른 사람이 귀하의 전적을 계속 검색할 수 있습니다.
  • 앱 삭제:
    기기의 모든 데이터(인증 토큰, 설정, 캐시)가 완전히 삭제됩니다. Firebase Analytics와 같은 통계 데이터 전송도 중단됩니다.

보안 조치

  • 인증 토큰은 기기의 안전한 암호화 저장소에 저장됩니다 (iOS: Keychain, Android: EncryptedSharedPreferences).
  • 외부 서버와의 통신은 HTTPS를 사용하여 암호화됩니다.
  • 인증 토큰과 같은 민감한 정보는 제3자와 공유되지 않습니다.

제3자 서비스

본 애플리케이션은 다음 제3자 서비스를 사용합니다:

Riot Games API

VALORANT 게임 데이터를 수집하는 데 사용됩니다.

  • Riot Games 개인정보 처리방침
  • Riot Games 서비스 약관

Firebase (Google)

앱 분석, 성능 모니터링, 크래시 리포팅 및 보안(무단 사용 방지)에 사용됩니다.

  • Google 개인정보 처리방침
  • Firebase 개인정보 보호 정보

Google AdMob

광고 제공에 사용됩니다. 사용자에게 적절한 광고를 표시하기 위해 광고 식별자 및 기기 정보가 수집 및 사용될 수 있습니다.

  • Google 광고 – 정책 및 약관
