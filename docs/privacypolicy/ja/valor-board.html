Valor Board プライバシーポリシー

最終更新日: 2026年4月14日

当アプリのご利用に当たって、以下のプライバシーポリシーにご理解頂いた上で利用することに同意するものとします。

ユーザーの皆様には、アプリの初回利用時またはポリシーの改定時に、同意画面にて最新のポリシーをご確認いただいています。

対象年齢

当アプリは16歳以上の方を対象としています。これはRiot Gamesのアカウント作成要件に準拠しています。16歳未満の方は保護者の同意を得た上でご利用ください。

収集・利用するデータ

Riot Games APIを通じて取得するデータ

  • Riot ID（ゲームネーム#タグライン）
  • アカウント情報（PUUID等の識別子）
  • マッチ履歴・戦績データ
  • ランキング情報

当アプリでは、Riot Games APIを通じてプレイヤーのマッチ履歴やランク情報などを取得・表示します。

これらの個人に紐づく戦績情報（マッチ履歴、詳細な統計情報、ダッシュボード機能等）の閲覧には、データの主体性を確認し保護するため、Riot Sign On (RSO) によるご本人様の認証（オプトイン）を必須としています。

RSOを通じて認証を行うことで、お客様は自身のプレイヤーデータが本アプリによって取得・分析され、表示されることに同意（オプトイン）したものとみなされます。

端末に保存するデータ

  • 認証トークン（安全な暗号化ストレージに保存）
  • ユーザー設定・アプリ設定
  • キャッシュデータ（ゲームコンテンツ情報等）
  • ラインナップ（定点）機能に使用する画像および動画（端末内にのみ保存され、外部サーバーへは送信されません）

サーバーに送信するデータ

  • Firebase Analytics: アプリ使用状況（個人特定情報は含まれません）
  • Firebase Performance Monitoring: アプリのパフォーマンスデータ（通信速度、画面描画速度等）
  • Firebase Crashlytics: クラッシュレポート（デバイス情報含む）
  • Cloud Firestore: ユーザーのPUUID、Riot ID（ゲームネーム#タグライン）、同意情報、登録日時、および取得されたマッチ詳細データ（戦績の保存、検索の高速化、および統計活用のため）
  • Firebase App Check: アプリと端末の真正性確認のためのトークン（Google Play Integrity API / Apple DeviceCheck / App Attest）
  • Firebase Authentication: ログイン認証、PUUIDの管理（ユーザーの識別）
  • Google AdMob: 広告識別子（IDFA/AAID）、デバイス情報、広告の表示・クリックなどの対話情報（広告配信および分析のため）

データの保存と削除

データの保存場所

  • 端末内ストレージ: 認証情報、設定、キャッシュ
  • Firebaseサーバー（Google Cloud）: 分析データ、パフォーマンスデータ、クラッシュレポート
  • Cloud Firestore（Google Cloud / 東京リージョン）: Opt-inユーザーの識別子（PUUID）、マッチ詳細データ
  • Firebase Authentication（Google Cloud / 東京リージョン）: 認証トークン、PUUID
  • Google AdMobサーバー: 広告関連データ

取得されたマッチデータは、API制限の回避、検索の高速化、およびRiot APIから取得できなくなった過去の戦績を永続的に確認できるようにするため、Firebaseサーバー上に保存されます。機能提供のために上記FirebaseサービスおよびGoogle AdMobを利用しています。

データの保持期間

  • 端末内データ: アプリをアンインストールするまで
  • Firebase Analytics: Googleのデータ保持ポリシーに従う
  • Firebase Performance Monitoring: 90日間
  • Firebase Crashlytics: 90日間
  • Google AdMob: Googleのデータ保持ポリシーに従う

データの削除方法

端末内のデータはアプリをアンインストールすることで削除されます。FirebaseおよびAdMobに送信されたデータについてはGoogleのポリシーに従って処理されます。

ユーザーの権利とオプトアウト

ユーザーは、自身のデータに関して以下の権利を有します：

  • データ取得への同意取り消し（オプトインの解除）
  • 端末内データの完全削除
  • パーソナライズド広告のオプトアウト（端末設定による）

権限の行使およびデータ削除の方法

以下の操作を行うことで、データの利用停止および削除が可能です：

  • アプリからのログアウト（RSO連携の解除）:
    アプリ内の設定画面からログアウトを行ってください。ログアウト時に『戦績を非公開にする』オプションを選択することで、サーバー上のオプトイン登録情報を削除することができます。削除しない場合、データは保持され検索可能な状態が維持されます。
  • アプリのアンインストール:
    端末内の全てのデータ（認証トークン、設定、キャッシュ）が完全に削除されます。また、Firebase Analyticsなどの統計データの送信も停止します。

セキュリティ対策

  • 認証トークンは端末の安全な暗号化ストレージ（iOS: Keychain、Android: EncryptedSharedPreferences）に保存されます
  • 外部サーバーへの通信はHTTPSを使用し暗号化されています
  • 認証トークン等の機密情報は第三者と共有されません

第三者サービス

当アプリは以下の第三者サービスを利用しています：

Riot Games API

VALORANTのゲームデータを取得するために使用します。

  • Riot Games プライバシーノーティス
  • Riot Games 利用規約

Firebase (Google)

アプリの分析、パフォーマンスの監視、クラッシュレポート、およびセキュリティ保護（不正利用の防止）に使用します。

  • Google プライバシーポリシー
  • Firebase プライバシー情報

Google AdMob

広告配信のために使用します。ユーザーに適切な広告を表示するために、広告識別子やデバイス情報を取得・利用する場合があります。

  • Google 広告 – ポリシーと規約

プライバシーポリシーの変更

本ポリシーは必要に応じて更新されることがあります。その際、アプリ起動時に新しいポリシーへの再同意をお願いする場合があります。
